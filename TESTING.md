# Guia de Testes Beta - VisualizadorApp

Obrigado por participar do teste beta do VisualizadorApp! Este documento orienta como usar o app e reportar problemas.

## 📱 Instalação

1. Receba o arquivo `app-release.apk`
2. No seu dispositivo Android, vá para **Configurações > Segurança**
3. Ative "Fontes desconhecidas" (permitir instalação de apps externos)
4. Abra o arquivo APK e selecione "Instalar"
5. Aguarde a instalação completar

## 🚀 Começando

### Primeira Execução
- Faça login ou crie uma conta
- Explore as principais telas (Cardápios, Reservas, Dashboard)
- Teste a navegação entre abas

## ✅ Áreas de Teste Prioritárias

### 1. Autenticação
- [ ] Login com email e senha
- [ ] Criar nova conta
- [ ] Recuperação de senha
- [ ] Logout

### 2. Visualização de Cardápios
- [ ] Cardápio do dia exibe corretamente
- [ ] Cardápio semanal carrega todos os dias
- [ ] Busca de cardápios por ingrediente funciona
- [ ] Histórico carrega cardápios anteriores
- [ ] Sistema de favoritos salva corretamente

### 3. Sistema de Reservas
- [ ] Criar nova reserva
- [ ] Cancelar reserva existente
- [ ] Notificações funcionam
- [ ] Status das reservas atualiza corretamente

### 4. Gestão (Admin)
- [ ] Upload de imagens dos pratos
- [ ] Edição de cardápios
- [ ] Gestão de funcionários
- [ ] Visualização de estatísticas

### 5. Performance
- [ ] App carrega sem travamentos
- [ ] Navegação é fluida
- [ ] Imagens carregam rapidamente
- [ ] Sem consumo excessivo de bateria
